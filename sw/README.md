# sw: perangkat lunak host

`pynq/` berisi seluruh perangkat lunak host (jalur AXI4-Lite): skrip papan, penyiapan paket di laptop, dan driver PYNQ. Fusi skor audio dengan gejala klinis
dilakukan di host (`pynq/papan/fusi.py`; pelatihannya di `pynq/laptop/fit_fusi.py`). Host UART, direktori benchmark, dan direktori fusi yang kosong
dihapus pada 2026-10-22 (ada di riwayat git).
